# Ticket: Feed de posts con paginación infinita

- **ID del Ticket:** `fase7-0004`
- **Fase:** `Frontend Flutter`
- **Estado:** `Abierto`
- **Prioridad:** `Media`

---

## Descripción

Implementar el feed principal de posts con paginación infinita en Flutter. Aunque las APIs de posts están en Fase 3 (pendiente), este ticket crea la UI con datos mock para demostrar la funcionalidad social principal de la aplicación.

---

## Criterios de Aceptación

- [ ] Feed principal implementado en Home tab
- [ ] Cards de posts con Material Design
- [ ] Paginación infinita con scroll automático
- [ ] UI implementada con datos mock realistas
- [ ] Posts con texto, imágenes, autor, fecha, comunidad
- [ ] Botones de interacción: me gusta, comentar, compartir (mock)
- [ ] Pull-to-refresh para actualizar feed
- [ ] Loading states durante carga de más posts
- [ ] Performance fluida (60fps, <100ms interactions)
- [ ] Funciona offline básico (caché de posts mock)

---

## Detalles Técnicos y Notas de Implementación

**Pantallas a implementar:**
- `lib/features/posts/screens/feed_screen.dart`
- `lib/features/posts/widgets/post_card.dart`
- `lib/features/posts/widgets/post_interactions.dart`

**Datos mock para desarrollo:**
```dart
class Post {
  final int id;
  final String content;
  final List<String> imageUrls;
  final User author;
  final Community community;
  final DateTime createdAt;
  final int likesCount;
  final int commentsCount;
  final bool isLiked;
}
```

**Funcionalidades UI:**
- ListView con infinite scroll
- RefreshIndicator para pull-to-refresh
- PostCard con layout atractivo
- InteractionBar con botones de acción
- Shimmer loading para estados de carga
- Cached network images para performance

**Paginación infinita:**
- ScrollController para detectar final de lista
- Loading indicator al cargar más posts
- Manejo de estados: loading, loaded, error, end
- Caché local para offline básico

**Preparación para APIs futuras:**
```dart
// Fase 3 APIs a integrar posteriormente
GET /api/posts/?page=1&limit=20
POST /api/posts/{id}/like/
POST /api/posts/{id}/comments/
```
