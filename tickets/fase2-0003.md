## Descripción

Implementar las APIs para gestión de membresías en comunidades **predefinidas**. Los usuarios pueden unirse/salir de comunidades existentes creadas por administradores del sistema. Incluye gestión de roles, aprobaciones y notificaciones básicas de membresía.

**Nota:** Las comunidades son predefinidas y creadas solo por administradores del sistema para mantener control de calidad y evitar spam.

**🚀 Funcionalidad Futura:** En fases posteriores se implementará la capacidad para que usuarios regulares puedan crear sus propias comunidades, con sistemas de aprobación, restricciones de creación y moderación automática para prevenir spam y mantener la calidad del contenido.

**Validaciones de negocio:**
```python
def join_community(user, community):
    # Verificar si ya es miembro
    if CommunityMembership.objects.filter(user=user, community=community).exists():
        raise ValidationError("Ya eres miembro de esta comunidad")
    
    # Verificar límite de miembros
    if community.max_members and community.member_count >= community.max_members:
        raise ValidationError("La comunidad ha alcanzado el límite de miembros")
    
    # Crear membresía
    status = 'pending' if community.requires_approval else 'active'
    membership = CommunityMembership.objects.create(
        user=user,
        community=community,
        role='member',
        status=status
    )
    
    # Actualizar contador si es activa inmediatamente
    if status == 'active':
        community.member_count = F('member_count') + 1
        community.save(update_fields=['member_count'])
```

**Signals para estadísticas:**
```python
@receiver(post_save, sender=CommunityMembership)
def update_member_count_on_join(sender, instance, created, **kwargs):
    if created and instance.is_active:
        instance.community.member_count = F('member_count') + 1
        instance.community.save(update_fields=['member_count'])

@receiver(post_delete, sender=CommunityMembership)
def update_member_count_on_leave(sender, instance, **kwargs):
    if instance.is_active:
        instance.community.member_count = F('member_count') - 1
        instance.community.save(update_fields=['member_count'])
```

**Permisos custom:**
```python
class IsCommunityMember(BasePermission):
    def has_object_permission(self, request, view, obj):
        return CommunityMembership.objects.filter(
            user=request.user,
            community=obj,
            is_active=True
        ).exists()

class IsCommunityModerator(BasePermission):
    def has_object_permission(self, request, view, obj):
        return CommunityMembership.objects.filter(
            user=request.user,
            community=obj,
            role__in=['moderator', 'admin'],
            is_active=True
        ).exists()
```
