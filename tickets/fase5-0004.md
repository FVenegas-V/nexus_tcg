## Descripción

Implementar sistema de notificaciones por email como fallback para actividad crítica, reutilizando la infraestructura de emails ya existente. Los usuarios recibirán emails para eventos importantes cuando no han visto las notificaciones in-app por un período determinado.

**Objetivo:** Asegurar que los usuarios no pierdan actividad importante en la plataforma, especialmente valoraciones de reputación y comentarios en sus posts, mediante notificaciones email inteligentes.

**Resultado esperado:** Sistema automatizado de emails que actúa como red de seguridad para el sistema de polling, con templates profesionales y configuración de frecuencia.

### Extensión del EmailService Existente

```python
# Reutilizar la infraestructura existente en users/email_service.py
class NotificationEmailService(EmailService):
    
    def send_rating_notification_email(self, user, rating):
        """Enviar email cuando recibe nueva valoración"""
        if not self._should_send_email(user, 'NEW_RATING'):
            return False
            
        template_context = {
            'user': user,
            'rating': rating,
            'rated_by': rating.rated_by,
            'app_url': settings.FRONTEND_URL,
        }
        
        return self.send_email(
            to_email=user.email,
            subject=f'Nueva valoración recibida - Nexus TCG',
            template_name='notifications/new_rating_email.html',
            context=template_context
        )
    
    def _should_send_email(self, user, notification_type):
        """Verificar si debe enviar email basado en preferencias y timing"""
        # Verificar preferencias del usuario
        prefs = user.notification_preferences
        if not prefs.get(f'email_{notification_type.lower()}', True):
            return False
            
        # Verificar rate limiting (máximo 1 email/tipo/día)
        return self._check_rate_limit(user, notification_type)
```

### Task Celery para Procesamiento Diferido
```python
from celery import shared_task

@shared_task
def send_notification_email_delayed(user_id, notification_type, object_id, delay_hours=6):
    """
    Enviar email si el usuario no ha visto la notificación in-app después del delay
    """
    user = User.objects.get(id=user_id)
    
    # Verificar si ya vio la notificación in-app
    notification_seen = Notification.objects.filter(
        user=user,
        type=notification_type,
        related_object_id=object_id,
        is_read=True
    ).exists()
    
    if not notification_seen:
        # No ha visto la notificación, enviar email
        NotificationEmailService().send_notification_email(
            user, notification_type, object_id
        )
```

### Signal Integration Mejorado
```python
from django.db.models.signals import post_save
from django.dispatch import receiver

@receiver(post_save, sender=UserRating)
def notify_new_rating(sender, instance, created, **kwargs):
    if created:
        # Crear notificación in-app inmediatamente
        Notification.objects.create(
            user=instance.rated_user,
            type='NEW_RATING',
            title=f'Nueva valoración de {instance.rated_by.username}',
            message=f'Has recibido una valoración de {instance.rating} estrellas',
            related_object=instance
        )
        
        # Programar email de respaldo para 24 horas después
        send_notification_email_delayed.apply_async(
            args=[instance.rated_user.id, 'NEW_RATING', instance.id],
            countdown=24 * 60 * 60  # 24 horas
        )
```

### Modelo de Preferencias
```python
class NotificationPreferences(models.Model):
    user = models.OneToOneField(User, on_delete=models.CASCADE)
    
    # Preferencias in-app (siempre habilitadas)
    app_new_posts = models.BooleanField(default=True)
    app_comments = models.BooleanField(default=True)
    app_ratings = models.BooleanField(default=True)
    
    # Preferencias email
    email_ratings = models.BooleanField(default=True)
    email_comments = models.BooleanField(default=True)
    email_weekly_summary = models.BooleanField(default=True)
    
    # Frecuencia de resumen
    summary_frequency = models.CharField(
        max_length=10,
        choices=[('daily', 'Diario'), ('weekly', 'Semanal'), ('never', 'Nunca')],
        default='weekly'
    )
```

## Comentarios y Discusión

**Timing Inteligente:** Los emails se envían solo si el usuario no ha visto la notificación in-app. Para valoraciones (críticas para reputación) el delay es 24h, para comentarios 6h.

**Reutilización:** Aprovechar completamente la infraestructura de emails ya implementada en Fase 1, incluyendo templates, configuración SMTP y manejo de errores.

**Escalabilidad:** Usar Celery tasks para el procesamiento diferido evita bloquear las operaciones principales de la app. El rate limiting previene spam accidental.
