## Descripción

Implementar los modelos de datos fundamentales para el sistema de publicaciones sociales: Posts, Comments y Reactions. Estos modelos formarán la base del sistema de contenido social de Nexus TCG, donde:

1. **Los posts se crean DENTRO de comunidades específicas** (usuario debe navegar a la comunidad)
2. **El feed HOME muestra posts destacados** de las comunidades a las que el usuario está suscrito
3. **Sistema de engagement** con comentarios threading y reacciones emoji

Los modelos deben seguir las mejores prácticas de Django, incluir validaciones robustas, índices de performance y triggers automáticos para mantener contadores actualizados.

## Comentarios y Discusión

### Consideraciones de Escalabilidad
- Los contadores de comentarios y reacciones se actualizarán en tiempo real via signals
- Para escalabilidad futura, considerar mover contadores a cache (Redis) si el volumen crece
- Las imágenes se almacenarán en cloud storage (AWS S3), solo URLs en BD

### Seguridad
- Validación estricta de URLs de imágenes para prevenir XSS
- Sanitización de contenido HTML si se permite formato rico
- Rate limiting a nivel de modelo para prevenir spam (implementar en fase posterior)

### Flujo de Creación de Posts
- **Contexto de Comunidad**: Posts solo se crean desde páginas interiores de comunidades
- **Verificación de Membresía**: Usuario debe ser miembro activo para crear posts
