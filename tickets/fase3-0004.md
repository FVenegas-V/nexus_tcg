## Descripción

Implementar el sistema completo de reacciones para posts y comentarios, permitiendo a los usuarios expresar emociones mediante emojis estándar (like, love, laugh, wow, sad, angry). El sistema debe ser eficiente, prevenir reacciones duplicadas y proporcionar métricas en tiempo real.

Las reacciones serán una pieza clave para el engagement y algoritmos de feed, proporcionando feedback inmediato y fomentando la interacción social en las comunidades TCG.

### Modelo Reaction (Optimizado)
```python
class Reaction(models.Model):
    REACTION_TYPES = [
        ('like', '👍'),
        ('love', '❤️'),
        ('laugh', '😂'),
        ('wow', '😮'),
        ('sad', '😢'),
        ('angry', '😠'),
    ]
    
    user = models.ForeignKey(User, on_delete=models.CASCADE)
    content_type = models.ForeignKey(ContentType, on_delete=models.CASCADE)
    object_id = models.PositiveIntegerField()
    content_object = GenericForeignKey('content_type', 'object_id')
    reaction_type = models.CharField(max_length=10, choices=REACTION_TYPES)
    created_at = models.DateTimeField(auto_now_add=True)
    
    class Meta:
        unique_together = ['user', 'content_type', 'object_id']
        indexes = [
            models.Index(fields=['content_type', 'object_id', 'reaction_type']),
            models.Index(fields=['user', 'created_at']),
        ]
```

@receiver([post_save, post_delete], sender=Reaction)
def update_reaction_counts(sender, instance, **kwargs):
    """Actualizar reaction_count en Post/Comment automáticamente"""
    content_object = instance.content_object
    if content_object:
        content_object.reaction_count = content_object.reactions.count()
        content_object.save(update_fields=['reaction_count'])

## Comentarios y Discusión

### Performance Optimizations
- **Contadores denormalizados**: Mantener reaction_count en Post/Comment
- **Índices compuestos**: (content_type, object_id, reaction_type) para breakdowns
- **Cache warming**: Pre-calcular breakdowns para posts populares
- **Batch operations**: Actualizar contadores en batches para alta concurrencia

### UX Considerations
- **Feedback inmediato**: Optimistic updates en frontend
- **Visual feedback**: Animaciones para agregar/quitar reacciones
- **Accessibility**: Soporte de keyboard y screen readers
- **Tooltips**: Mostrar usuarios que reaccionaron en hover

### Analytics y Métricas
Las reacciones proporcionarán datos valiosos para:
- **Algoritmos de feed**: Contenido con más engagement sube en ranking
- **User insights**: Preferencias y comportamiento de usuarios
- **Community health**: Ratio de reacciones positivas vs negativas
- **Content moderation**: Auto-flagging de contenido con muchas reacciones negativas

### Rate Limiting
- **Prevenir spam**: Máximo 100 reacciones por usuario por hora
- **Cooldown**: 1 segundo entre cambios de reacción
- **Detection**: Patterns sospechosos de bots reaccionando

### Future Enhancements (Post-MVP)
- **Custom reactions**: Permitir comunidades crear sus propios emojis
- **Reaction analytics**: Dashboard para creadores de contenido
- **Notification system**: Notificar cuando contenido recibe reacciones
- **Gamification**: Badges por recibir cierto número de reacciones
