## Detalles Técnicos y Notas de Implementación

**Pantallas a implementar:**
- `lib/features/profile/screens/profile_screen.dart`
- `lib/features/profile/screens/edit_profile_screen.dart`
- `lib/features/profile/screens/change_password_screen.dart`
- `lib/features/settings/screens/settings_screen.dart`

**APIs ya implementadas en Fase 1:**
```dart
// Obtener perfil
GET /api/users/me/
Headers: { "Authorization": "Bearer {token}" }

// Actualizar perfil
PUT /api/users/me/
Body: {
  "first_name": "Nuevo Nombre",
  "last_name": "Nuevo Apellido",
  "email": "newemail@example.com"
}

// Cambiar contraseña
PUT /api/users/me/password/
Body: {
  "old_password": "oldpass123",
  "new_password": "newpass123"
}
```

**Funcionalidades del perfil:**
- Header con avatar, nombre completo, username
- Información de cuenta (fecha registro, email verificado)
- Botones: Editar perfil, Cambiar contraseña, Configuraciones
- Estadísticas placeholder (posts, comunidades, reputación)

**Configuraciones disponibles:**
- Notificaciones (preparación para futuro)
- Tema de la aplicación
- Información de la app (versión, términos, privacidad)
- Logout con confirmación
