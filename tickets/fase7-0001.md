## Detalles Técnicos y Notas de Implementación

**Pantallas a implementar:**
- `lib/features/auth/screens/login_screen.dart`
- `lib/features/auth/screens/register_screen.dart`
- `lib/features/auth/widgets/auth_form.dart`

**APIs a integrar:**
```dart
POST /api/auth/login/
Body: { "username": "user@example.com", "password": "password123" }

POST /api/auth/register/
Body: { 
  "email": "user@example.com",
  "username": "username123", 
  "password": "SecurePass123",
  "password_confirm": "SecurePass123"
}
```

**Configuración requerida:**
- Provider para gestión de estado de autenticación
- Dio configurado para llamadas HTTP
- SecureStorage para tokens JWT
- Go router para navegación
- Tema Material personalizado según mockup

**Diseño específico según mockup:**
```dart
// Colores del mockup identificados
primaryRed: Color(0xFFE74C3C),     // Rojo principal del header
secondaryOrange: Color(0xFFF39C12), // Coral/naranja para gradientes
backgroundColor: Color(0xFFF5F5F5),  // Fondo general
cardColor: Colors.white,             // Cards blancos
textPrimary: Color(0xFF2C3E50),      // Texto principal
textHint: Color(0xFF95A5A6),         // Placeholders

// Elementos de diseño del mockup:
- Header: LinearGradient(primaryRed → secondaryOrange) + logo Nexus TCG
- Cards: Container con BorderRadius.circular(16), BoxShadow sutil
- Campos: OutlineInputBorder con bordes grises, hint text gris
- Botones: LinearGradient matching header, BorderRadius.circular(25)
- Typography: GoogleFonts.roboto() para consistencia
```

**Layout específico del mockup:**
- Login: "Bienvenido de nuevo" + Email + Password + "¿Olvidaste la contraseña?"
- Register: "Registro" + "Crea una nueva cuenta" + Username + Email + Password
- Navegación cruzada: "¿No tienes cuenta? Regístrate" / "¿Ya tienes cuenta? Login"

**Estados UI a manejar:**
- Inicial/vacío
- Validando campos
- Enviando request
- Autenticación exitosa
- Error de validación
- Error de red/servidor
