## Descripción

Implementar el sistema backend completo de notificaciones usando estrategia de polling MVP. Crear modelos Django, APIs REST optimizadas y sistema de signals automáticos para generar notificaciones en tiempo real.

**Objetivo:** Construir la base backend que permita notificar a usuarios sobre actividad relevante en la plataforma usando polling inteligente en lugar de Firebase push notifications.

**Resultado esperado:** APIs funcionales que soporten consultas eficientes de notificaciones no leídas y sistema automático de generación de notificaciones.

## Detalles Técnicos y Notas de Implementación

### Modelo Notification
```python
class Notification(models.Model):
    NOTIFICATION_TYPES = [
        ('NEW_POST', 'Nuevo post en comunidad'),
        ('NEW_COMMENT', 'Comentario en tu post'),
        ('COMMENT_REPLY', 'Respuesta a tu comentario'),
        ('NEW_RATING', 'Nueva valoración recibida'),
    ]
    
    user = models.ForeignKey(User, on_delete=models.CASCADE)
    type = models.CharField(max_length=20, choices=NOTIFICATION_TYPES)
    title = models.CharField(max_length=255)
    message = models.TextField()
    content_type = models.ForeignKey(ContentType, on_delete=models.CASCADE)
    object_id = models.PositiveIntegerField()
    related_object = GenericForeignKey('content_type', 'object_id')
    is_read = models.BooleanField(default=False)
    priority = models.CharField(max_length=10, default='NORMAL')
    created_at = models.DateTimeField(auto_now_add=True)
```

### API Optimizada para Polling
```python
# Endpoint especial para polling cada 30 segundos
@api_view(['GET'])
def notifications_unread(request):
    notifications = Notification.objects.filter(
        user=request.user,
        is_read=False
    ).order_by('-created_at')[:5]
    
    return Response({
        'count': notifications.count(),
        'latest': NotificationSerializer(notifications, many=True).data
    })
```

### Signals Automáticos
- Signal en Post.save() → Notificar miembros de comunidad
- Signal en Comment.save() → Notificar autor del post/comentario padre  
- Signal en UserRating.save() → Notificar usuario valorado

## Comentarios y Discusión

**Decisión de Arquitectura:** Usar polling en lugar de WebSockets/Firebase para simplicidad MVP. El endpoint `/unread/` está optimizado para consultas frecuentes cada 30 segundos sin impactar performance.

**Optimización de Performance:** Las consultas de polling solo traen count + últimas 5 notificaciones para minimizar transferencia de datos. Cache de Django puede implementarse posteriormente si es necesario.
