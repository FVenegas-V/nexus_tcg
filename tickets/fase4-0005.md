## Descripción

Crear un dashboard completo de reputación que se integre tanto en el perfil personal del usuario como en los perfiles públicos visibles por otros usuarios. Este dashboard debe presentar de forma visual y comprensible el estado de reputación, tendencias, logros y métricas clave que ayuden a construir confianza en la comunidad TCG.

El dashboard debe ser informativo para el propietario del perfil y persuasivo para otros usuarios que consideran interactuar o intercambiar.

```python
class ReputationDashboardViewSet(viewsets.ReadOnlyModelViewSet):
    """
    ViewSet para dashboard de reputación
    """
    permission_classes = [IsAuthenticated]
    
    @action(detail=True, methods=['get'])
    def dashboard(self, request, pk=None):
        """Dashboard completo de reputación"""
        user = self.get_object()
        
        # Verificar permisos de visibilidad
        if not self.can_view_reputation(request.user, user):
            return Response({'detail': 'No tienes permisos para ver esta reputación'}, 
                          status=403)
        
        data = {
            'user_info': self.get_user_basic_info(user),
            'reputation_summary': self.get_reputation_summary(user),
            'rating_distribution': self.get_rating_distribution(user),
            'temporal_trends': self.get_temporal_trends(user),
            'achievements': self.get_achievements(user),
            'interaction_breakdown': self.get_interaction_breakdown(user),
            'recent_highlights': self.get_recent_highlights(user),
            'community_standing': self.get_community_standing(user),
        }
        
        return Response(data)
    
    def can_view_reputation(self, viewer, target_user):
        """Verificar si el viewer puede ver la reputación del target_user"""
        if viewer == target_user:
            return True
        
        # Verificar configuraciones de privacidad
        privacy_settings = getattr(target_user, 'privacy_settings', None)
        if privacy_settings and privacy_settings.hide_reputation_from_others:
            return False
        
        return True
```

### Cache Strategy

```python
class ReputationDashboardCache:
    """
    Estrategia de cache para dashboard de reputación
    """
    
    @staticmethod
    def get_cache_key(user_id, viewer_id=None):
        """Generar clave de cache específica"""
        if viewer_id:
            return f"reputation_dashboard:{user_id}:viewer:{viewer_id}"
        return f"reputation_dashboard:{user_id}:public"
    
    @staticmethod
    def cache_dashboard_data(user_id, data, viewer_id=None, timeout=3600):
        """Cachear datos del dashboard por 1 hora"""
        cache_key = ReputationDashboardCache.get_cache_key(user_id, viewer_id)
        cache.set(cache_key, data, timeout)
    
    @staticmethod
    def invalidate_user_cache(user_id):
        """Invalidar cache cuando cambia la reputación"""
        pattern = f"reputation_dashboard:{user_id}:*"
        cache.delete_pattern(pattern)

# Signal para invalidar cache
@receiver(post_save, sender=UserRating)
def invalidate_reputation_cache(sender, instance, **kwargs):
    ReputationDashboardCache.invalidate_user_cache(instance.rated_user.id)
```

## Comentarios y Discusión

### Visualización de Datos

- **Gráficos Responsivos**: Chart.js o similar para tendencias temporales
- **Indicadores Visuales**: Progress bars para próximos logros
- **Color Coding**: Verde para métricas positivas, amarillo para neutrales

### Gamificación

- **Progreso Visible**: Mostrar progreso hacia próximo logro
- **Rareza de Logros**: Sistema de badges comunes vs raros
- **Comparación Social**: "Top 10% en tu comunidad principal"

### Performance

- **Cache Inteligente**: Cache por 1 hora, invalidar solo cuando necesario
- **Lazy Loading**: Cargar métricas menos importantes bajo demanda
- **Batch Queries**: Optimizar queries para múltiples usuarios
