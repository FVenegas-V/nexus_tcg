## Detalles Técnicos y Notas de Implementación

**Pantallas a implementar:**
- `lib/features/notifications/screens/notifications_screen.dart`
- `lib/features/notifications/widgets/notification_item.dart`
- `lib/features/notifications/widgets/notification_badge.dart`

**Tipos de notificaciones mock:**
```dart
enum NotificationType {
  mention,    // "@usuario te mencionó en un post"
  like,       // "A usuario le gustó tu post"
  comment,    // "usuario comentó tu post"
  follow,     // "usuario te siguió"
  community   // "Nuevo post en comunidad X"
}

class AppNotification {
  final int id;
  final NotificationType type;
  final String title;
  final String message;
  final DateTime createdAt;
  final bool isRead;
  final String? relatedId; // para navegación
}
```

**Funcionalidades UI:**
- Lista con diferentes layouts según tipo
- Indicador visual de leído/no leído
- Time stamps relativos ("hace 2 horas")
- Agrupación por fecha
- Swipe actions para marcar como leído
- Badge con contador en BottomNavigationBar

**Preparación para futuro:**
- Estructura para Firebase FCM
- Local notifications para testing
- Deep linking para navegación desde notificaciones
- Background sync preparado
