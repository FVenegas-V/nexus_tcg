## Descripción Original

Implementar un sistema robusto de upload y gestión de imágenes para posts, incluyendo validación de archivos, optimización automática, almacenamiento eficiente y serving optimizado. El sistema debe manejar múltiples imágenes por post, diferentes formatos y tamaños de dispositivos.

Este sistema será fundamental para la experiencia social de Nexus TCG, permitiendo a los usuarios compartir cartas, colecciones, eventos y momentos de juego de manera visual y atractiva.

### Modelo PostImage
```python
class PostImage(models.Model):
    post = models.ForeignKey(Post, on_delete=models.CASCADE, related_name='images')
    original_filename = models.CharField(max_length=255)
    file_path = models.CharField(max_length=500)
    file_size = models.PositiveIntegerField()  # bytes
    width = models.PositiveIntegerField()
    height = models.PositiveIntegerField()
    mime_type = models.CharField(max_length=50)
    
    # Múltiples resoluciones
    thumbnail_url = models.URLField(max_length=500, blank=True)
    medium_url = models.URLField(max_length=500, blank=True)
    large_url = models.URLField(max_length=500, blank=True)
    original_url = models.URLField(max_length=500)
    
    uploaded_at = models.DateTimeField(auto_now_add=True)
    is_active = models.BooleanField(default=True)
    
    class Meta:
        ordering = ['uploaded_at']
        indexes = [
            models.Index(fields=['post', 'is_active']),
            models.Index(fields=['uploaded_at']),
        ]
```

## Comentarios y Discusión

### Security Considerations
- **MIME validation**: Verificar tipo real del archivo, no solo extensión
- **Image validation**: Usar PIL para confirmar que es imagen válida
- **Malware scanning**: Integración con ClamAV o servicio cloud
- **Upload limits**: Rate limiting por usuario (10 imágenes/hora)
- **File quarantine**: Procesar uploads en entorno aislado

### Performance Optimizations
- **Async processing**: Upload inmediato, processing en background con Celery
- **Progressive upload**: Mostrar imagen original mientras se procesan tamaños
- **CDN integration**: Headers cache apropiados, ETags para invalidación
- **Lazy loading**: Cargar imágenes bajo demanda en frontend
- **WebP conversion**: Formato moderno con mejor compresión

### User Experience
- **Progress indicators**: Barra de progreso para uploads largos
- **Drag & drop**: Interface intuitiva para múltiples archivos
- **Preview**: Mostrar preview antes de upload final
- **Error recovery**: Retry automático para fallos de red
- **Mobile optimization**: Compresión extra para conexiones lentas

### Storage Strategy
- **Development**: Local filesystem con Django's FileSystemStorage
- **Production**: AWS S3 con CloudFront CDN
- **Backup**: Replicación automática entre regiones
- **Cleanup**: Job nocturno para eliminar archivos huérfanos
- **Monitoring**: Alertas por uso de storage y costos

### Future Enhancements (Post-MVP)
- **Image recognition**: Auto-tagging de cartas con AI
- **EXIF handling**: Remover metadatos sensibles automáticamente
- **Video support**: Expandir a videos cortos (GIFs animados)
- **Watermarking**: Marca de agua opcional para proteger contenido
- **Compression options**: Permitir usuarios elegir calidad vs tamaño
