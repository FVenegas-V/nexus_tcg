## Descripción

Implementar el sistema core de valoraciones entre usuarios de Nexus TCG, permitiendo que los jugadores puedan calificar a otros usuarios con estrellas del 1 al 5 después de interacciones. Este sistema es fundamental para construir confianza en la comunidad TCG y facilitar intercambios seguros entre usuarios.

El sistema debe prevenir abuso, permitir solo una valoración por usuario, y proporcionar contexto útil para las valoraciones.

## Detalles Técnicos y Notas de Implementación

### Modelo de Base de Datos

```python
class UserRating(models.Model):
    """
    Modelo para valoraciones entre usuarios
    """
    rater = models.ForeignKey(User, on_delete=models.CASCADE, related_name='ratings_given')
    rated_user = models.ForeignKey(User, on_delete=models.CASCADE, related_name='ratings_received')
    rating = models.PositiveSmallIntegerField(
        validators=[MinValueValidator(1), MaxValueValidator(5)]
    )
    comment = models.TextField(max_length=500, blank=True)
    interaction_type = models.CharField(
        max_length=20,
        choices=[
            ('post_interaction', 'Interacción en Post'),
            ('comment_interaction', 'Interacción en Comentario'),
            ('community_interaction', 'Interacción en Comunidad'),
            ('direct_interaction', 'Interacción Directa'),
        ]
    )
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)
    is_active = models.BooleanField(default=True)
    
    class Meta:
        unique_together = ['rater', 'rated_user']
        ordering = ['-created_at']
```

### APIs a Implementar

1. **`POST /api/users/{id}/rate/`** - Crear/actualizar valoración
2. **`GET /api/users/{id}/ratings/`** - Ver valoraciones recibidas (paginado)
3. **`GET /api/ratings/my-ratings/`** - Mis valoraciones dadas
4. **`DELETE /api/ratings/{rating_id}/`** - Eliminar mi valoración (soft delete)

### Validaciones de Negocio

- **Anti-Gaming**: Usuario no puede valorarse a sí mismo
- **Una valoración por par**: Solo una valoración entre dos usuarios específicos
- **Rango válido**: Solo 1-5 estrellas permitidas
- **Comentario moderado**: Filtro básico de contenido inapropiado
- **Rate Limiting**: Máximo 5 valoraciones por día por usuario

## Comentarios y Discusión

### Consideraciones de UX
- Valoración debe ser fácil pero reflexiva
- Comentario opcional para justificar valoraciones extremas (1-2 ⭐)
- Feedback claro cuando se actualiza una valoración existente

### Anti-Abuse Measures
- Rate limiting para prevenir spam de valoraciones
- Sistema de reportes para valoraciones maliciosas
- Algoritmo futuro para detectar patrones de valoraciones falsas

### Performance
- Índices en campos de búsqueda frecuente (rated_user, created_at)
- Paginación obligatoria para listados de valoraciones
- Cache de estadísticas agregadas (promedio, conteo)
