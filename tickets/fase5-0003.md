## Descripción

Implementar la interfaz de usuario completa para notificaciones en Flutter, incluyendo badges con contadores en la navegación principal, pantalla de lista de notificaciones y interacciones para marcar como leídas.

**Objetivo:** Crear una experiencia de usuario intuitiva y visualmente atractiva para gestionar notificaciones, siguiendo los patrones de Material Design ya establecidos en la app.

**Resultado esperado:** UI funcional de notificaciones que se integre perfectamente con la navegación existente y proporcione feedback visual claro sobre actividad nueva.

---

- [ ] **Badge en BottomNavigationBar** muestra contador de notificaciones no leídas

### NotificationCard Personalizado
```dart
class NotificationCard extends StatelessWidget {
  final NotificationModel notification;
  final VoidCallback? onTap;

  Widget build(BuildContext context) {
    return Card(
      margin: EdgeInsets.symmetric(horizontal: 16, vertical: 4),
      child: ListTile(
        leading: _buildNotificationIcon(),
        title: Text(
          notification.title,
          style: TextStyle(
            fontWeight: notification.isRead ? FontWeight.normal : FontWeight.bold,
          ),
        ),
        subtitle: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            Text(notification.message),
            SizedBox(height: 4),
            Text(
              _formatTimestamp(notification.createdAt),
              style: Theme.of(context).textTheme.caption,
            ),
          ],
        ),
        trailing: notification.isRead ? null : Container(
          width: 8,
          height: 8,
          decoration: BoxDecoration(
            color: Colors.coral,
            shape: BoxShape.circle,
          ),
        ),
        onTap: onTap,
      ),
    );
  }

  Widget _buildNotificationIcon() {
    switch (notification.type) {
      case 'NEW_POST':
        return Icon(Icons.article, color: Colors.blue);
      case 'NEW_COMMENT':
        return Icon(Icons.comment, color: Colors.green);
      case 'COMMENT_REPLY':
        return Icon(Icons.reply, color: Colors.orange);
      case 'NEW_RATING':
        return Icon(Icons.star, color: Colors.amber);
      default:
        return Icon(Icons.notifications, color: Colors.grey);
    }
  }
}
```

### Provider Integration
```dart
class NotificationProvider extends ChangeNotifier {
  List<NotificationModel> _notifications = [];
  bool _isLoading = false;
  int _unreadCount = 0;

  Future<void> markAsRead(String notificationId) async {
    try {
      await ApiService.put('/api/notifications/$notificationId/read/');
      
      // Actualizar estado local
      final index = _notifications.indexWhere((n) => n.id == notificationId);
      if (index != -1) {
        _notifications[index] = _notifications[index].copyWith(isRead: true);
        _unreadCount = max(0, _unreadCount - 1);
        notifyListeners();
      }
    } catch (e) {
      // Manejar error
    }
  }

  Future<void> markAllAsRead() async {
    try {
      await ApiService.put('/api/notifications/read-all/');
      
      _notifications = _notifications.map((n) => n.copyWith(isRead: true)).toList();
      _unreadCount = 0;
      notifyListeners();
    } catch (e) {
      // Manejar error
    }
  }
}
```

## Comentarios y Discusión

**Consistencia Visual:** Usar los mismos colores coral y patrones de Material Design ya establecidos en la app. Los badges deben seguir el estilo visual del resto de la aplicación.

**Navegación Contextual:** Cuando el usuario toca una notificación de "nuevo comentario", debe navegar directamente al post con el comentario resaltado. Para valoraciones, al perfil de reputación, etc.

**Performance:** Para listas grandes de notificaciones, considerar usar `ListView.builder` con lazy loading. El Provider debe manejar paginación eficientemente.
