# Ticket: Configuración de Preferencias de Notificaciones

- **ID del Ticket:** `fase5-0005`
- **Fase:** `Fase 5: Sistema de Notificaciones MVP`
- **Estado:** `Abierto`
- **Prioridad:** `Media`

---

## Descripción

Implementar sistema completo de configuración de preferencias de notificaciones, permitiendo a los usuarios personalizar qué notificaciones recibir, con qué frecuencia y por qué canales (in-app, email). Incluye tanto backend APIs como pantalla Flutter de configuración.

**Objetivo:** Dar control granular a los usuarios sobre su experiencia de notificaciones, mejorando satisfacción y reduciendo unsubscribes, mientras se mantiene engagement efectivo.

**Resultado esperado:** Pantalla de configuración intuitiva y APIs backend que permitan personalización completa del sistema de notificaciones.

---

## Criterios de Aceptación

- [ ] **Modelo NotificationPreferences** con todas las opciones configurables
- [ ] **API GET /api/notifications/preferences/** para obtener configuración actual

- [ ] **Validación en tiempo real** con feedback visual de cambios

```python
class NotificationPreferences(models.Model):
    user = models.OneToOneField(User, on_delete=models.CASCADE, related_name='notification_preferences')
    
    # Notificaciones in-app (siempre habilitadas para MVP)
    app_new_posts = models.BooleanField(default=True, help_text="Nuevos posts en comunidades")
    app_new_comments = models.BooleanField(default=True, help_text="Comentarios en tus posts")
    app_comment_replies = models.BooleanField(default=True, help_text="Respuestas a tus comentarios")
    app_new_ratings = models.BooleanField(default=True, help_text="Nuevas valoraciones")
    
    # Notificaciones por email
    email_new_ratings = models.BooleanField(default=True, help_text="Valoraciones por email")
    email_important_comments = models.BooleanField(default=True, help_text="Comentarios importantes")
    email_weekly_summary = models.BooleanField(default=True, help_text="Resumen semanal")
    
    # Configuración de frecuencia
    summary_frequency = models.CharField(
        max_length=10,
        choices=[
            ('immediate', 'Inmediato'),
            ('daily', 'Diario'),
            ('weekly', 'Semanal'),
            ('never', 'Nunca')
        ],
        default='weekly'
    )
    
    # Configuración avanzada (opcional para MVP)
    quiet_hours_start = models.TimeField(null=True, blank=True, help_text="Inicio de horas silenciosas")
    quiet_hours_end = models.TimeField(null=True, blank=True, help_text="Fin de horas silenciosas")
    
    updated_at = models.DateTimeField(auto_now=True)
    
    class Meta:
        verbose_name = "Notification Preferences"
        verbose_name_plural = "Notification Preferences"
    
    def __str__(self):
        return f"Preferencias de {self.user.username}"
```

### API ViewSet para Preferencias
```python
class NotificationPreferencesViewSet(viewsets.ViewSet):
    permission_classes = [IsAuthenticated]
    
    def list(self, request):
        """GET /api/notifications/preferences/"""
        preferences, created = NotificationPreferences.objects.get_or_create(
            user=request.user
        )
        serializer = NotificationPreferencesSerializer(preferences)
        return Response(serializer.data)
    
    def update(self, request):
        """PUT /api/notifications/preferences/"""
        preferences, created = NotificationPreferences.objects.get_or_create(
            user=request.user
        )
        serializer = NotificationPreferencesSerializer(
            preferences, 
            data=request.data, 
            partial=True
        )
        if serializer.is_valid():
            serializer.save()
            return Response(serializer.data)
        return Response(serializer.errors, status=400)
    
    @action(detail=False, methods=['post'])
    def reset_to_defaults(self, request):
        """POST /api/notifications/preferences/reset/"""
        preferences, created = NotificationPreferences.objects.get_or_create(
            user=request.user
        )
        
        # Restaurar a valores por defecto
        for field in preferences._meta.fields:
            if hasattr(field, 'default') and field.default is not None:
                setattr(preferences, field.name, field.default)
        
        preferences.save()
        serializer = NotificationPreferencesSerializer(preferences)
        return Response(serializer.data)
```

### Pantalla Flutter de Configuración
```dart
class NotificationSettingsScreen extends StatefulWidget {
  @override
  _NotificationSettingsScreenState createState() => _NotificationSettingsScreenState();
}

class _NotificationSettingsScreenState extends State<NotificationSettingsScreen> {
  NotificationPreferences? _preferences;
  bool _isLoading = true;
  bool _isSaving = false;

  @override
  void initState() {
    super.initState();
    _loadPreferences();
  }

  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: Text('Configuración de Notificaciones'),
        actions: [
          TextButton(
            onPressed: _resetToDefaults,
            child: Text('Restaurar'),
          ),
        ],
      ),
      body: _isLoading ? _buildLoadingState() : _buildSettingsForm(),
    );
  }

  Widget _buildSettingsForm() {
    return ListView(
      padding: EdgeInsets.all(16),
      children: [
        _buildSectionHeader('Notificaciones en la App'),
        _buildAppNotificationTile(
          'Nuevos posts en comunidades',
          'Recibe notificaciones cuando haya posts nuevos',
          _preferences!.appNewPosts,
          (value) => setState(() => _preferences!.appNewPosts = value),
        ),
        _buildAppNotificationTile(
          'Comentarios en tus posts',
          'Cuando alguien comenta en tus publicaciones',
          _preferences!.appNewComments,
          (value) => setState(() => _preferences!.appNewComments = value),
        ),
        
        SizedBox(height: 24),
        _buildSectionHeader('Notificaciones por Email'),
        
        _buildEmailNotificationTile(
          'Nuevas valoraciones',
          'Recibe emails cuando recibas valoraciones',
          _preferences!.emailNewRatings,
          (value) => setState(() => _preferences!.emailNewRatings = value),
        ),
        
        _buildFrequencySelector(),
        
        SizedBox(height: 32),
        ElevatedButton(
          onPressed: _isSaving ? null : _savePreferences,
          child: _isSaving 
            ? CircularProgressIndicator()
            : Text('Guardar Configuración'),
        ),
      ],
    );
  }

  Widget _buildAppNotificationTile(String title, String subtitle, bool value, Function(bool) onChanged) {
    return SwitchListTile(
      title: Text(title),
      subtitle: Text(subtitle),
      value: value,
      onChanged: onChanged,
      activeColor: Theme.of(context).primaryColor,
    );
  }

  Widget _buildFrequencySelector() {
    return Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        Text(
          'Frecuencia de resúmenes',
          style: Theme.of(context).textTheme.subtitle1,
        ),
        SizedBox(height: 8),
        DropdownButtonFormField<String>(
          value: _preferences!.summaryFrequency,
          decoration: InputDecoration(
            border: OutlineInputBorder(),
            contentPadding: EdgeInsets.symmetric(horizontal: 16, vertical: 8),
          ),
          items: [
            DropdownMenuItem(value: 'immediate', child: Text('Inmediato')),
            DropdownMenuItem(value: 'daily', child: Text('Diario')),
            DropdownMenuItem(value: 'weekly', child: Text('Semanal')),
            DropdownMenuItem(value: 'never', child: Text('Nunca')),
          ],
          onChanged: (value) {
            setState(() => _preferences!.summaryFrequency = value!);
          },
        ),
      ],
    );
  }

  Future<void> _savePreferences() async {
    setState(() => _isSaving = true);
    
    try {
      await ApiService.put(
        '/api/notifications/preferences/',
        data: _preferences!.toJson(),
      );
      
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(content: Text('Configuración guardada exitosamente')),
      );
    } catch (e) {
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(content: Text('Error al guardar configuración')),
      );
    } finally {
      setState(() => _isSaving = false);
    }
  }
}
```

```dart
class NotificationPreferences {

  final bool appNewComments;
  final bool appCommentReplies;
  final bool appNewRatings;
  
  final bool emailNewRatings;
  final bool emailImportantComments;
  final bool emailWeeklySummary;

  NotificationPreferences({
    required this.appNewPosts,
    required this.appNewComments,
    required this.appCommentReplies,
    required this.appNewRatings,
    required this.emailNewRatings,
    required this.emailImportantComments,
    required this.emailWeeklySummary,
    required this.summaryFrequency,
  });

  factory NotificationPreferences.fromJson(Map<String, dynamic> json) {
    return NotificationPreferences(
      appNewPosts: json['app_new_posts'] ?? true,
      appNewComments: json['app_new_comments'] ?? true,
      appCommentReplies: json['app_comment_replies'] ?? true,
      appNewRatings: json['app_new_ratings'] ?? true,
      emailNewRatings: json['email_new_ratings'] ?? true,
      emailImportantComments: json['email_important_comments'] ?? true,
      emailWeeklySummary: json['email_weekly_summary'] ?? true,
      summaryFrequency: json['summary_frequency'] ?? 'weekly',
    );
  }

  Map<String, dynamic> toJson() {
    return {
      'app_new_posts': appNewPosts,
      'app_new_comments': appNewComments,

      'app_new_ratings': appNewRatings,
      'email_new_ratings': emailNewRatings,
      'email_important_comments': emailImportantComments,
      'email_weekly_summary': emailWeeklySummary,
      'summary_frequency': summaryFrequency,
    };
  }
}
```

## Comentarios y Discusión

**UX Consideration:** La pantalla debe estar accesible desde el perfil de usuario y también tener un link directo desde emails ("configurar preferencias").

**Valores por Defecto:** Configuración inicial optimizada para engagement sin ser molesta. Los usuarios pueden ajustar según sus preferencias.
