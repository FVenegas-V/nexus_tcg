## Descripción

Implementar el algoritmo inteligente para calcular y mantener actualizada la reputación de usuarios basada en las valoraciones recibidas. El algoritmo debe considerar múltiples factores para generar un score de reputación justo y resistente a manipulación, que refleje la confiabilidad real del usuario en la comunidad TCG.

El sistema debe actualizar automáticamente las reputaciones y manejar el cálculo de forma eficiente para escalar con el crecimiento de usuarios.

## Detalles Técnicos y Notas de Implementación

### Algoritmo de Reputación Propuesto

```python
def calculate_user_reputation(user):
    """
    Calcula la reputación de un usuario basada en valoraciones recibidas
    
    Factores considerados:
    1. Promedio de valoraciones (peso base)
    2. Antigüedad de valoraciones (decay temporal)
    3. Credibilidad del evaluador (peso por reputación)
    4. Volumen total de valoraciones (confianza estadística)
    5. Distribución de valoraciones (detectar manipulación)
    """
    
    ratings = user.ratings_received.filter(is_active=True)
    
    if not ratings.exists():
        return 0.0, 0
    
    total_weighted_score = 0
    total_weight = 0
    now = timezone.now()
    
    for rating in ratings:
        # Factor 1: Score base (1-5)
        base_score = rating.rating
        
        # Factor 2: Decay temporal (más reciente = más peso)
        days_old = (now - rating.created_at).days
        temporal_weight = max(0.1, 1.0 - (days_old / 365))  # Decay anual
        
        # Factor 3: Credibilidad del evaluador
        rater_credibility = min(2.0, rating.rater.reputation_score / 2.5)
        if rater_credibility < 0.5:
            rater_credibility = 0.5  # Peso mínimo
        
        # Factor 4: Peso combinado
        combined_weight = temporal_weight * rater_credibility
        
        total_weighted_score += base_score * combined_weight
        total_weight += combined_weight
    
    # Factor 5: Confianza estadística (penaliza pocas valoraciones)
    rating_count = ratings.count()
    confidence_factor = min(1.0, rating_count / 10)  # Confianza máxima con 10+ ratings
    
    # Cálculo final
    if total_weight > 0:
        weighted_average = total_weighted_score / total_weight
        final_score = weighted_average * confidence_factor
        return round(final_score, 2), rating_count
    
    return 0.0, 0
```

```python
# Task de Celery
@shared_task
def update_user_reputation_task(user_id):
    """Task para actualizar reputación en background"""
    try:
        user = User.objects.get(id=user_id)
        score, count = calculate_user_reputation(user)
        
        User.objects.filter(id=user_id).update(
            reputation_score=score,
            reputation_count=count,
            updated_at=timezone.now()
        )
        
        # Log del cambio
        logger.info(f"Reputation updated for user {user.username}: {score}")
        
    except User.DoesNotExist:
        logger.error(f"User {user_id} not found for reputation update")
```

### Management Command

```python
class Command(BaseCommand):
    """
    Comando para recalcular todas las reputaciones
    python manage.py recalculate_reputations
    """
    
    def add_arguments(self, parser):
        parser.add_argument('--batch-size', type=int, default=100)
        parser.add_argument('--async', action='store_true')
    
    def handle(self, *args, **options):
        users = User.objects.filter(is_active=True)
        
        if options['async']:
            # Procesar en background con Celery
            for user_id in users.values_list('id', flat=True):
                update_user_reputation_task.delay(user_id)
        else:
            # Procesar sincrónicamente
            for user in users:
                score, count = calculate_user_reputation(user)
                user.reputation_score = score
                user.reputation_count = count
                user.save(update_fields=['reputation_score', 'reputation_count'])
```

## Comentarios y Discusión

### Parámetros del Algoritmo

Los siguientes parámetros pueden ser ajustados basado en métricas reales:

- **Decay temporal**: Actualmente 365 días para 90% de decay
- **Peso máximo evaluador**: 2.0x para usuarios con reputación 5.0
- **Confianza estadística**: 10 valoraciones para confianza máxima
- **Peso mínimo evaluador**: 0.5x para usuarios con baja reputación

### Consideraciones de Gaming

- **Círculos de valoración mutua**: Detectar mediante análisis de grafos
- **Cuentas fake**: Peso reducido para usuarios nuevos o con poca actividad
- **Valoraciones extremas**: Análisis estadístico para detectar outliers

### Performance y Escalabilidad

- **Cache de reputaciones**: Redis cache para scores frecuentemente consultados
- **Batch processing**: Recálculos masivos solo en horarios de bajo tráfico
- **Índices optimizados**: Índices compuestos para queries de reputación
