# Ticket: Navegación principal con bottom tabs

- **ID del Ticket:** `fase7-0002`
- **Fase:** `Frontend Flutter`
- **Estado:** `Abierto`
- **Prioridad:** `Alta`

---

## Descripción

Implementar la navegación principal de la aplicación con bottom tabs que permita acceso a las secciones principales: Home feed, Comunidades, Perfil y Configuraciones. Esta navegación será el hub central de la aplicación móvil.

---

## Criterios de Aceptación

- [ ] Bottom navigation bar implementada con Material Design
- [ ] Tabs principales: Home, Comunidades, Perfil, Configuraciones
- [ ] Navegación fluida entre tabs con mantenimiento de estado
- [ ] AppBar personalizada con logo Nexus TCG
- [ ] Drawer lateral opcional para funciones adicionales
- [ ] Verificación de estado de autenticación en startup
- [ ] Logout funcional que limpie tokens y redirija a login
- [ ] UI es intuitiva y sigue Material Design
- [ ] Performance fluida (60fps, <100ms interactions)
- [ ] Navegación condicional según estado de autenticación

---

## Detalles Técnicos y Notas de Implementación

**Estructura de navegación:**
```dart
lib/features/
├── home/screens/home_screen.dart
├── communities/screens/communities_screen.dart
├── profile/screens/profile_screen.dart
└── settings/screens/settings_screen.dart
```

**Bottom tabs a implementar:**
1. **Home**: Feed principal (placeholder inicial)
2. **Comunidades**: Lista de comunidades (placeholder inicial)
3. **Perfil**: Perfil del usuario autenticado
4. **Configuraciones**: Opciones de app y logout

**Navegación requerida:**
- BottomNavigationBar con 4 tabs
- AppBar personalizada con logo
- Scaffold principal que contenga todas las pantallas
- Go router configurado para deep linking
- Mantenimiento de estado entre tabs

**Verificación de autenticación:**
```dart
GET /api/users/me/
Headers: { "Authorization": "Bearer {access_token}" }
```
