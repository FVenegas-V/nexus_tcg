# Ticket: Listado y detalle de comunidades

- **ID del Ticket:** `fase7-0003`
- **Fase:** `Frontend Flutter`
- **Estado:** `Abierto`
- **Prioridad:** `Media`

---

## Descripción

Implementar las pantallas de listado y detalle de comunidades en Flutter. Aunque las APIs de comunidades aún no están implementadas (Fase 2 pendiente), este ticket crea la UI con datos mock para demostrar la funcionalidad y preparar la integración futura.

---

## Criterios de Aceptación

- [ ] Pantalla de listado de comunidades con Material Design
- [ ] Pantalla de detalle de comunidad individual
- [ ] UI implementada con datos mock realistas
- [ ] Cards de comunidades con imagen, nombre, descripción, miembros
- [ ] Búsqueda básica de comunidades (filtro local por ahora)
- [ ] Pull-to-refresh para actualizar listado
- [ ] Navegación fluida entre listado y detalle
- [ ] UI preparada para integración futura con APIs reales
- [ ] Performance fluida (60fps, <100ms interactions)
- [ ] Loading states y manejo de errores UI
