**ID**: fase1-0004  
**Fase**: 1 - Autenticación y Usuarios  
**Prioridad**: Alta  
**Estimación**: 6-8 horas

## Descripción

Implementar sistema de verificación de email para nuevos usuarios mediante tokens de verificación enviados por correo electrónico.

## Objetivos

- ✅ Forzar verificación de email antes de activar cuenta
- ✅ Enviar email de verificación automáticamente al registrarse
- ✅ Proveer endpoint para reenvío de verificación
- ✅ Manejar estados de cuenta no verificada

## Funcionalidades Requeridas

### Backend APIs
- ✅ **Modificar Registro**: Crear usuarios con `is_verified=False` por defecto
- ✅ **Token Verificación**: Generar token UUID único para cada usuario  
- ✅ **Envío Email**: Email automático de verificación post-registro
- ✅ **Endpoint Verificación**: `GET /api/auth/verify-email/<token>/`
- ✅ **Reenvío Verificación**: `POST /api/auth/resend-verification/`
- 🔄 **Protección APIs**: Bloquear usuarios no verificados en endpoints protegidos

### Validaciones y Lógica
- ✅ **Expiración Token**: Tokens válidos por 24 horas
- 🔄 **Rate Limiting**: Max 3 reenvíos por hora por usuario
- 🔄 **Estado Usuario**: Verificar email antes de permitir login completo  
- 🔄 **Limpieza Automática**: Eliminar tokens expirados (tarea programada)

## Endpoints a Implementar

### 1. GET /api/auth/verify-email/\<token\>/
Verificar email usando token enviado por correo.

**Respuesta 200:**
```json
{
    "success": true,
    "message": "Email verificado exitosamente",
    "data": {
        "user_id": 1,
        "email": "usuario@example.com",
        "verified_at": "2025-08-06T10:30:00Z"
    }
}
```

**Errores:**
- 400: Token inválido o expirado
- 404: Token no encontrado

### 2. POST /api/auth/resend-verification/
Reenviar email de verificación.

**Request:**
```json
{
    "email": "usuario@example.com"
}
```

**Respuesta 200:**
```json
{
    "success": true,
    "message": "Email de verificación reenviado",
    "data": {
        "sent_to": "usuario@example.com",
        "expires_at": "2025-08-07T10:30:00Z"
    }
}
```

## Modelos de Base de Datos

### EmailVerificationToken
```python
class EmailVerificationToken(models.Model):
    user = models.OneToOneField(User, on_delete=models.CASCADE, related_name='verification_token')
    token = models.UUIDField(default=uuid.uuid4, unique=True)
    created_at = models.DateTimeField(auto_now_add=True)
    expires_at = models.DateTimeField()
    used_at = models.DateTimeField(null=True, blank=True)
    
    def is_valid(self):
        return self.used_at is None and timezone.now() < self.expires_at
    
    def mark_as_used(self):
        self.used_at = timezone.now()
        self.save()
```
