# Ticket: Creación de posts con imágenes

- **ID del Ticket:** `fase7-0005`
- **Fase:** `Frontend Flutter`
- **Estado:** `Abierto`
- **Prioridad:** `Baja`

---

## Descripción

Implementar la funcionalidad de creación de posts con soporte para texto e imágenes. Aunque las APIs de posts están en Fase 3 (pendiente), este ticket crea la UI completa con validaciones y preparación para integración futura.

---

## Criterios de Aceptación

- [ ] Pantalla de creación de posts con Material Design
- [ ] Editor de texto con validaciones de longitud
- [ ] Selector de comunidad donde publicar
- [ ] Soporte para agregar múltiples imágenes
- [ ] Preview de imágenes seleccionadas con opción de eliminar
- [ ] Validaciones de contenido y tamaño de imágenes
- [ ] Loading state durante "publicación" (mock)
- [ ] Navegación de vuelta al feed tras "publicar"
- [ ] UI es intuitiva y sigue Material Design
- [ ] Performance fluida al manejar imágenes

---

## Detalles Técnicos y Notas de Implementación

**Pantallas a implementar:**
- `lib/features/posts/screens/create_post_screen.dart`
- `lib/features/posts/widgets/image_picker_widget.dart`
- `lib/features/posts/widgets/community_selector.dart`

**Funcionalidades requeridas:**
- TextFormField para contenido del post
- Dropdown/selector para elegir comunidad
- Image picker (cámara/galería)
- Grid preview de imágenes seleccionadas
- Validaciones en tiempo real
- Botón flotante para crear post desde feed

**Validaciones UI:**
- Contenido: mínimo 10 caracteres, máximo 1000
- Imágenes: máximo 5 imágenes, tamaño <5MB cada una
- Comunidad: debe seleccionar una comunidad
- Preview en tiempo real del post

**Image handling:**
```dart
dependencies:
  image_picker: ^1.0.0
  cached_network_image: ^3.2.0
  
// Funcionalidades
- Selección múltiple de imágenes
- Compresión automática
- Preview con eliminación individual
- Indicador de tamaño y límites
```

**Preparación para APIs futuras:**
```dart
// Fase 3 APIs a integrar posteriormente

Body: {
  "content": "Texto del post",
  "community": 1,
  "images": [File1, File2, ...]

```
