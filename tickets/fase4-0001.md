## Descripción

Implementar la funcionalidad para que los usuarios puedan ver y navegar los perfiles públicos de otros usuarios en la aplicación Nexus TCG. Esta funcionalidad es fundamental como prerequisito para el sistema de valoraciones y reputación, ya que los usuarios necesitan poder evaluar a otros jugadores antes de realizar intercambios o valoraciones.

El perfil público debe mostrar información relevante para la comunidad TCG: actividad reciente, comunidades donde participa, reputación actual, y posts destacados, manteniendo siempre la privacidad del usuario.

## Detalles Técnicos y Notas de Implementación

### APIs a Implementar

```python
# Nuevo ViewSet en users/views.py
class UserProfileViewSet(viewsets.ReadOnlyModelViewSet):
    """
    ViewSet para perfiles públicos de usuarios
    Solo lectura, sin modificación de perfiles ajenos
    """
    queryset = User.objects.filter(is_active=True)
    serializer_class = UserPublicProfileSerializer
    permission_classes = [IsAuthenticated]
```

### Endpoints Específicos

1. **`GET /api/users/{id}/profile/`** - Perfil completo
2. **`GET /api/users/{id}/activity/`** - Actividad reciente (posts, comentarios)
3. **`GET /api/users/{id}/communities/`** - Comunidades donde es miembro
4. **`GET /api/users/{id}/posts/`** - Posts públicos del usuario (paginado)

### Serializers Nuevos

```python
class UserPublicProfileSerializer(serializers.ModelSerializer):
    """Serializer para información pública del perfil"""
    post_count = serializers.IntegerField(read_only=True)
    comment_count = serializers.IntegerField(read_only=True)
    community_count = serializers.IntegerField(read_only=True)
    recent_posts = PostListSerializer(many=True, read_only=True)
    communities = CommunityListSerializer(many=True, read_only=True)
    bio_preview = serializers.SerializerMethodField()
    
    class Meta:
        model = User
        fields = ['id', 'username', 'first_name', 'last_name', 
                 'avatar_url', 'bio', 'bio_preview', 'date_joined', 'reputation_score',
                 'reputation_count', 'post_count', 'comment_count', 
                 'community_count', 'recent_posts', 'communities']
    
    def get_bio_preview(self, obj):
        """Generar preview de biografía si es muy larga"""
        if obj.bio and len(obj.bio) > 200:
            return obj.bio[:200] + "..."
        return obj.bio
```

## Comentarios y Discusión

### Consideraciones de UX
- El perfil debe ser informativo pero no abrumador
- **Biografía**: Mostrar biografía completa pero con preview si es muy larga (>200 chars)
- **Biografía vacía**: Mostrar placeholder amigable cuando el usuario no ha configurado biografía
- Enfoque en información relevante para decisiones de intercambio/confianza
- Navegación intuitiva desde cualquier mención del usuario

### Performance
- Implementar cache para perfiles frecuentemente visitados
- Considerar lazy loading para secciones menos importantes
- Optimizar queries para evitar timeouts en usuarios con mucha actividad

### Seguridad
- Validar permisos: usuarios solo pueden ver perfiles públicos
- Rate limiting para prevenir scraping masivo de perfiles
- Logging de accesos a perfiles para analytics y seguridad
