**Filtros Django Filter:**
```python
class CommunityFilter(FilterSet):
    search = CharFilter(method='filter_search')
    game_type = CharFilter()
    difficulty_level = CharFilter()
    category = NumberFilter()
    is_subscribed = BooleanFilter(method='filter_subscribed')
    
    def filter_search(self, queryset, name, value):
        return queryset.filter(
            Q(name__icontains=value) | 
            Q(description__icontains=value) |
            Q(tags__contains=[value])
        )
```

**Optimizaciones:**
- Select_related para created_by y category
- Prefetch_related para memberships del usuario
- Annotate para is_subscribed dinámico
- Cache de 5 minutos para listados populares
- Índices en campos de búsqueda y filtrado

**Paginación:**
- PageNumberPagination con max 50 items
- Configuración custom para diferentes tamaños
- Metadata de conteo total y enlaces

**Permisos:**
- Listado: AllowAny (público)
- Detalle: AllowAny (comunidades públicas), IsAuthenticated (privadas)
- Filtro is_subscribed: IsAuthenticated
